Wireframe hub

Internal review build of a broad payments provider directory, benchmarked against PayAtlas. Every template below is clickable. Yellow notes explain decisions. Version 2 adds banner, margin, sidebar, in-article and sponsored listing ads; striped boxes marked Sponsored are ad slots. Use the buttons bottom right to hide ads or notes and compare.

Margin skyscrapers only appear on screens 1560px and wider. Mobile adds a dismissible bottom anchor ad.

Pages not built in the wireframe

About, How we rank, Ownership, Roadmap, Contact and legal pages link here. "How we rank" and "Ownership" are launch requirements: they answer the neutrality question PayAtlas leaves open.

Links to unbuilt entities (other services, countries, providers) open the sample page for that template, with the intended slug in the query string.

Versions

The dark strip at the top switches between versions and keeps you on the same page. v1 (branch main) has no ads. v2 (branch v2) adds banner, margin, in-content and sponsored listing ads, plus an /advertise/ page; from there, switching to v1 goes to the home page.

On Vercel branch URLs the switch works automatically. On the production domain, set each version's url in data/versions.json on both branches, render and push. Locally there is only one version per server, so the other version shows as unset.
